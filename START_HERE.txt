C Drive Safe Cleaner v1.1.0-dev - Python 源码运行版

这是源码运行版，不是免安装 Python 的 EXE 版。
需要 Windows 11、Python 3.10 或以上版本（带 tkinter）。无第三方运行依赖。

1. 解压整个压缩包。
2. 在包含 config.json 和 src 文件夹的目录打开终端。
3. 输入：python -m src.main --gui

程序启动只扫描，不会自动删除文件。
勾选 SAFE 项后，可先点击“模拟所选项”。
真实清理需要输入大写 CLEAN，再点击清理按钮并确认弹窗。
真实清理会删除文件；请先阅读 SAFETY.md。
CAUTION 和 MANUAL 项只读展示。

此邮件包不包含 EXE、DLL 或 BAT 启动器；原版清理代码保持不变。
