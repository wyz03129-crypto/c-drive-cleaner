# M3 空间分析器实施记录

## 已交付

- C 盘递归只读统计和目录逐层展开数据；
- Top-N 大目录和大文件；
- 使用 `(volume/device, file index/inode)` 对硬链接去重；
- symlink、junction 和 reparse point 不跟随、不循环；
- 可取消扫描及取消后的部分结果；
- 无权限目录、无权限条目、跳过链接和硬链接重复量分别统计；
- 明确展示目录覆盖率，未知区域不按 0 字节解释；
- 版本化本地快照缓存，可立即显示上一次结果，但缓存不授予删除权；
- `analyze` CLI 展示容量、已用、可用、最大目录和最大文件；
- 可重复生成的 50 万文件基准脚本。

## 使用

```powershell
python -m cdrive_cleaner analyze --top 20
python -m cdrive_cleaner analyze --cached
python scripts/benchmark_analyzer.py --files 500000
```

`--cached` 会明确标出快照时间。缓存只用于快速显示，正式结果仍需重新扫描。

## 安全属性

- 分析结果的任意路径都不能直接转换成清理授权；
- 分析器完全不调用删除 API；
- 特殊文件和受保护目录可以被计量，但不会因此变成可清理项目；
- 文件身份只用于硬链接去重，不复用为 M2 清理计划；
- 无权限、元数据竞争和链接均导致覆盖率下降或跳过，不扩大推测值。

## 尚未宣称完成

- 100 万文件 P95 ≤ 90 秒必须在固定 Windows SSD 环境重复测量；
- Python `stat` 的逻辑大小不是 NTFS 精确分配大小；
- 当前缓存提供快速旧快照，不会在没有重新验证的情况下合并增量结果；
- 正式树形钻取、后台进度和取消界面属于 M5 GUI；
- 系统组件、Docker、WSL、休眠与还原点专项解释属于 M4。

M3 当前是可测试的分析 CLI，不是正式消费者界面。
